# Community code of conduct

We want AdForge discussions, workshops, and contributions to be welcoming to people of every background and experience level.

Be respectful, give constructive feedback, credit others' work, protect private information, and avoid harassment or exclusionary behavior. Project maintainers may remove content or participation that violates these expectations.

Report conduct concerns privately through the repository owner's GitHub profile. Good-faith reports will be reviewed promptly and handled with discretion.
